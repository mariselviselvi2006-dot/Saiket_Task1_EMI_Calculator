# Saiket Task 1 - EMI Calculator

## 📌 Project Overview
A simple and interactive Loan EMI Calculator developed using HTML, CSS, and JavaScript.

## 🚀 Features
- Enter loan amount
- Enter interest rate
- Select loan tenure
- Calculate monthly EMI
- User-friendly interface
- Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
